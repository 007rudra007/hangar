# Hangar Wiki

Welcome to the **Hangar (Flutter)** documentation!

## Project Overview
Hangar is a local-first Virtual Wardrobe and Virtual Try-On Android application ported to Flutter (`com.openwardrobe.app`).

## Technology Stack
- **Framework**: Flutter (Material 3 + `dynamic_color`)
- **Language**: Dart (`^3.5.0`)
- **Database**: SQLite (`sqflite`) & `shared_preferences`
- **Platform**: Android
